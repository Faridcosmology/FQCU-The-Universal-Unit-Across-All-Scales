Abstract
We define the Farid Quantum Command Unit (FQCU) as a conventional reference energy equal to that of a
photon with frequency 1 THz: E
F
= h × 1012 Hz = 6.62607015 × 10−22 J = 4.135667696 meV. The unit
enables dimensionally explicit comparisons of energy and mass-equivalent energy across particle physics,
bioenergetics, and astrophysics. Associated wavelength, period, and reduced scales can be constructed
using h, ħ and c, but these are not the same physical quantity as energy. Information-erasure energy
depends on temperature and protocol, and entropy requires its own thermodynamic definition. We retain
seven proposed falsification tests while distinguishing specified tests from documented preregistration and
unverified numerical outcomes. FQCU is a useful energy normalization, not a demonstrated fundamental
quantum, field, or physical coupling. The work identifies what would be required to elevate the convention
to a predictive theory.
Keywords: energy normalization; FQCU; dimensional analysis; photon frequency; Landauer bound; photosynthesis; SPARC;
hyperon polarization; falsifiability.
1. Introduction
Physical systems are described using units adapted to their scales. A fixed reference energy can facilitate
comparison, but changing units does not itself unify physical dynamics. This paper therefore separates
three claims: (i) exact unit conversion, (ii) useful associated reference scales, and (iii) hypothetical new
physics. Only (i) follows from the definition alone. The word “universal” refers to the applicability of energy
normalization, not to a universal dynamical law.

9. Cross-scale applications and limitations
9.1 Particle physics
Higgs, top-quark, proton and hyperon-related energy scales can be converted into FQCU. No
particle-physics interaction term, decay amplitude, or QFT prediction follows from this conversion. A claimed
STAR hyperon goodness-of-fit requires a traceable published dataset, observable definition, uncertainty
covariance, fitting code, model degrees of freedom and independent reproduction.
9.2 Bioenergetics and photosynthesis
For standard biochemical ATP hydrolysis ΔG°′ ≈ −30.5 kJ/mol, the magnitude per molecule is approximately
0.316 eV ≈ 76.4 FQCU. A condition-dependent ATP synthesis free-energy requirement of 50 kJ/mol
corresponds to approximately 0.518 eV ≈ 125.3 FQCU. These are different thermodynamic conditions and
should not be conflated. Eight absorbed photons at representative reaction-centre wavelengths (four at 680
nm and four at 700 nm) correspond to approximately 14.38 eV ≈ 3.48 × 103 FQCU. Photons also support
NADPH production and losses; their total energy is not wholly stored as ATP.

12. Reproducible conversion engine: specification and tests
A conversion engine can validate arithmetic but cannot verify a physical field theory. The following
compact, self-contained C++17 code provides unit conversion, associated length and time scales, and
assertions for inverse conversions. It distinguishes photon wavelength from reduced length and forbids
zero/negative energy in reciprocal-scale calculations.
#include <cmath>
#include <iostream>
#include <stdexcept>
constexpr double h = 6.62607015e-34; // J s
constexpr double c = 299792458.0; // m/s
constexpr double eV_J = 1.602176634e-19; // J/eV
constexpr double pi = 3.14159265358979323846;
constexpr double EF_J = h * 1.0e12;
constexpr double EF_eV = EF_J / eV_J;
double toFQCU(double energy_eV) { return energy_eV / EF_eV; }
double toEV(double nF) { return nF * EF_eV; }
double wavelength(double nF) {
if (nF <= 0) throw std::domain_error("positive energy required");
return h*c/(nF*EF_J);
}
double reducedLength(double nF) { return wavelength(nF)/(2*pi); }
double period(double nF) {
if (nF <= 0) throw std::domain_error("positive energy required");
return h/(nF*EF_J);
}

13. Conclusion and submission requirements
FQCU is a consistent, explicitly defined reference energy that can be applied across many physical scales.
Its associated wavelength, reduced length, period and reduced time follow from standard constants.
Landauer and ATP examples demonstrate condition-dependent energy accounting, not a new fundamental
quantum. Neither a universal field equation nor an independent microscopic FQCU coupling has been
established in this specification. Scientific value will depend on novel, quantitative, precommitted
predictions that survive comparisons with existing theories and independent datasets.
